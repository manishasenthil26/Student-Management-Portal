Student Management Portal

Project Description

The Student Management Portal is a static website developed using HTML5 and CSS. It provides a simple interface for students to explore courses, view information, and access registration and contact pages.

Technologies Used

HTML5

CSS3

GitHub

Pages Developed

Home

About

Student Registration

Courses

Contact

Features

Navigation between web pages

Student registration form

Course information displayed in a table

Contact information and message form

Responsive styling for smaller screens

How to Run

Download or clone the repository.

Open index.html in a web browser.

Use the navigation menu to visit the other pages.

Project Type

Static website for academic purposes.
